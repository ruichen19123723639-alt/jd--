# JD Agent 需求说明

## 1. 用户和问题

用户是正在求职的应届毕业生。

用户希望快速了解：
- 自己与岗位的匹配程度
- 已经具备哪些能力
- 缺少哪些能力
- 简历或面试应该重点补充什么

## 2. 输入

- 一份职位描述 JD
- 一份候选人资料 profile

## 3. 输出

- 岗位名称
- 核心技能
- 已匹配技能
- 缺少技能
- 匹配分数
- 每项判断对应的候选人资料证据
- 风险或未知信息
- 学习和准备建议

## 4. 系统流程

1. 从 JD 中提取岗位要求。
2. 从候选人资料中检索相关内容。
3. 使用 Python 计算确定性的技能匹配分数。
4. 使用模型生成解释和学习建议。
5. 返回结构化结果。
6. 用户确认后，再决定是否修改简历或投递。

## 5. 人和系统的分工

### 模型负责

- 理解 JD 文本
- 提取技能和职责
- 总结匹配情况
- 生成学习建议

### Python 程序负责

- 校验输入和输出格式
- 计算匹配分数
- 记录错误和耗时
- 重试临时失败的请求

### 用户负责

- 确认候选人资料是否真实
- 判断模型建议是否合理
- 决定是否修改简历和投递

## 6. 失败情况

- JD 为空：拒绝请求
- 候选人资料为空：返回无法判断
- 没有检索到证据：不得编造经历
- 模型输出格式错误：返回结构错误
- 模型超时：重试一次，仍失败则返回明确错误
- 技能要求为空：匹配分数默认为 100，但提示结果仅供参考

## 7. 评估指标

- 技能匹配计算测试通过率
- 模型结构化输出通过率
- 检索结果是否包含正确证据
- 无证据时是否停止编造
- 平均响应时间
- 模型请求失败率

## 8. 当前版本的验收标准

- `/analyze` 能返回结构化 JD 分析。
- `/agent-match` 能通过工具计算匹配分数。
- 匹配工具测试通过率为 5/5。
- RAG 能显示检索来源。
- 模型超时后能自动重试并返回明确错误。
- Docker 容器能够启动并访问 Swagger 文档。
